# DonutsZombies 🧟

A small **DayZ mod project** focused on creating custom zombie skins, accessories and other visual elements.

This project was created for **learning, experimentation and community collaboration**.

## About

DonutsZombies is an open project for the **DayZ community and students who are interested in learning about game modding**.

Feel free to explore the files, study how the project works, modify it, and use it as a starting point for your own projects.

You are also welcome to improve the existing project and contribute new ideas, fixes or features.

## What You Can Do

You are welcome to:

* Study the project structure
* Modify the existing files
* Create your own versions
* Use this project as a learning base
* Experiment with new ideas
* Create new features
* Fix or improve existing features
* Share improvements with the community

## Community & Learning

This repository is intended to be a **learning resource and an open starting point** for people interested in DayZ modding.

If you are a student, beginner, or simply someone interested in creating DayZ mods, feel free to experiment with this project and build something of your own.

If you find something that can be improved, **contributions and suggestions are welcome**.

The goal is not only to create a mod, but also to provide a project that others can learn from, modify and build upon.
